# handoffs/

Um arquivo por handoff, em `onda-<n>/<de>-para-<para>-<slug>.md`. Formato e regras completos em
`/AGENTS.md` → "Protocolo de handoff". Qualquer agente pode criar o próprio arquivo aqui; ninguém
edita o handoff criado por outro agente, exceto o destinatário atualizando `Status` e adicionando
`## Resolução`.
